# Greeting Card Generator

An interactive web application that turns user input into a personalized greeting card.

## How it's built

- The `index.html` and  `card.js` — Define the user interface and card-generation logic.
- style.css – Styles the greeting card generator and controls its layout, colors, fonts, and overall appearance.
